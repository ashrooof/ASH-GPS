# ASH GPS

**ASH GPS — © أشـــــــروف**

An ad-free Android location research and in-app QA workspace.

## Current release
- Version: 0.4.0
- Custom ASH monogram branding and owner credit.
- Premium light interface with Explore, Routes and Saved sections.
- Interactive OpenStreetMap view, place search and coordinate selection.
- Manual latitude/longitude entry and local route preview.

## Privacy and scope
- No advertising SDKs or ad placements are included.
- Internet access is used for map tiles and place search.
- Location simulation is limited to the app's own QA preview; it does not alter Android's device location or other apps.

## Build
Open with Android Studio and build the `app` debug variant.
