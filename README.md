# ASH GPS — Ultra Premium

A clean, ad-free Android location research and QA workspace.

## Current release
- Version: 0.3.0
- Premium light interface with Explore, Routes and Saved sections.
- Interactive OpenStreetMap view, place search and coordinate selection.
- Manual latitude/longitude entry and saved-point shortcut.
- Local visual route-preview controls.

## Privacy and scope
- No advertising SDKs or ad placements are included.
- The app requests internet access for map tiles and place search.
- It does not request device-location permission, alter Android's location provider, or affect other apps.
- Preview is an in-app QA visualization only.

## Build
Open with Android Studio and build the `app` debug variant.
